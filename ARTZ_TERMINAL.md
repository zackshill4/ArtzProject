# ARTZ Python Terminal

Terminal UI native untuk project ARTZ menggunakan Python + Rich.

## Menjalankan

1. cd ArtzProject
2. python -m pip install -r requirements.txt
3. python artz_terminal.py

Windows shortcut: jalankan run_artz.bat

## Command

help
status
profile
world
mission
clear
exit

Tidak membutuhkan browser atau HTML. UI dirender langsung di terminal menggunakan Rich/ANSI.
