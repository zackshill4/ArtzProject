# ARTZ Project — Terminal UI

A standalone cyber/dark-fantasy terminal interface for the ARTZ RPG project.

## Run
No build step or dependencies are required. Open `index.html` in a browser.

## Included
- ARTZ-themed command terminal
- Responsive layout
- Cyber scanline presentation
- Profile, world state, mission, network and loadout panels
- Interactive commands: `help`, `status`, `profile`, `world`, `clear`
